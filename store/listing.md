## 1. 商店列表（Store listing 分頁）

**名稱**（45 字元內）

```
Language Tutor in YouTube
```

> 名稱**不能以 YouTube 開頭**。YouTube 的品牌規範寫得很明確：應用程式名稱裡不能含
> YouTube 或其變體（例如不能叫「YouTube for Kids」），但可以在描述文字裡說明
> 「這是給 YouTube 用的工具」。所以 YouTube 放在後面當描述，不放在前面當品牌。
> 以後想改名的話這條還是要遵守。

**簡短說明**（132 字元內，與 `manifest.json` 的 `description` 一致）

```
每隔一段時間自動暫停 YouTube 影片，整理該段的單字與片語，並帶你一句一句複習。
```

**詳細說明**

```
看 YouTube 學語言最大的問題是：聽不懂的地方一閃而過，查完單字影片早就播到別的地方了。

這個擴充讓影片每播放約 30 秒就自動停一次，把這一段出現的單字、片語與文法整理出來，
再帶你一句一句複習，複習完按「繼續」接著播下一段。

■ 主要功能

・自動分段暫停：播到段落結尾自動停下，整理這一段的內容。也可以切成「連續播放」。
・逐句複習：點任何一句就重播那一句；0.75 倍速放慢跟讀。
・聽寫模式：先把原文模糊起來只靠聽力，點該句才揭曉。
・框選解說：在原文上用滑鼠拉出一小段，就能針對那幾個字問「在這句裡是什麼意思」。
・收藏與匯出：單字、片語、句子、文法都可以按 ★ 收藏，跨影片保存。
  匯出成 Excel 可開的表格，或 Anki 可直接匯入的檔案（支援單欄與分欄兩種格式）。
・不會讓你空等：背景會預先整理下一段，所以「停下來」通常等於「可以馬上開始學」。

■ 使用前請注意

・需要你自己的 AI API key（Anthropic 的 Claude 或 Google 的 Gemini，在設定頁二選一）。
  本擴充不提供也不代付 API 費用，費用由你與該供應商直接結算。
  可以選用較便宜的模型，分析結果也會快取，重看同一部影片不會重複付費。
・影片必須有字幕（YouTube 自動字幕也可以）。
・支援十種學習語言：法文、英文、日文、韓文、西班牙文、德文、義大利文、葡萄牙文、
  中文、俄文。多語字幕的影片會自動挑你設定的那一條，不是跟著你的 YouTube 帳號語言走。
・預設不會自動啟動。要在影片頁按「開始學習這部影片」或點工具列圖示才會開始運作。

■ 隱私

本擴充沒有伺服器，作者收不到你的任何資料。你的 API key、設定與生字本只存在本機瀏覽器。
只有在你主動啟動某支影片之後，該影片的字幕文字與標題會由你的瀏覽器直接送往你選擇的
AI 供應商進行分析。詳見隱私權政策。

開放原始碼：https://github.com/UncleLin332/youtube-language-tutor

■ 支持開發

本擴充免費、沒有廣告、不收集資料，也不從你付給 AI 供應商的費用裡抽成。
覺得好用的話可以請我喝杯咖啡，但完全不影響任何功能：
https://ko-fi.com/kappa46122
```

> 贊助連結放在詳細說明的最後面，不要放在開頭——商店列表只會先顯示前幾行，

## 2. 隱私權實務（Privacy practices 分頁）

**單一用途說明**（Single purpose）

```
在 YouTube 影片頁上自動分段暫停，並整理該段字幕中的單字、片語與文法，協助使用者學習外語。
```

**權限理由**（每一項都要填，照抄即可）

| 欄位 | 填什麼 |
|---|---|
| `storage` | 儲存使用者的設定（AI 供應商、API key、學習語言、段落長度）與收藏的生字本。沒有這個權限，使用者每次開啟瀏覽器都要重新設定，收藏的單字也無法跨影片保存。 |
| `unlimitedStorage` | 每段字幕的分析結果會快取在本機，讓使用者重看同一部影片時不必重複呼叫付費 API。長時間使用後快取會超過 `storage.local` 的預設 10MB 上限，因此需要此權限。擴充內建自動清理機制，只保留最近的快取。 |
| 主機權限 `https://api.anthropic.com/*` | 將字幕內容送往 Anthropic 的 Claude API 進行分析，使用的是使用者自己填入的 API key。內容指令碼受 CORS 限制無法直接呼叫，因此請求由 service worker 發出。 |
| 主機權限 `https://generativelanguage.googleapis.com/*` | 同上，供使用者選擇 Google Gemini 作為分析供應商時使用。兩者擇一，不會同時呼叫。 |
| 內容指令碼 `*://www.youtube.com/*` | 在 YouTube 影片頁插入學習面板、取得使用者所學語言的字幕軌、並控制影片的暫停與單句重播。字幕是透過 YouTube 自己的播放器 API 切換到目標語言後取得的，使用者原本的字幕設定會在讀取完畢後還原。<br><br>比對範圍必須涵蓋整個 `www.youtube.com` 而非只有 `/watch`，因為 YouTube 是單頁應用程式：使用者從首頁點進影片時不會重新載入頁面，若只在 `/watch` 注入，指令碼就不會被載入。擴充只在 `/watch` 頁面上實際動作，其餘頁面不做任何事。 |

> **後台只有一個「要求網站存取權限的理由」欄位**，上面三個主機相關的列要合成一段貼進去
> （上限 1000 字）。下面這段是合併版，449 字：

```
本擴充需要三個網域的存取權，用途各自獨立。

www.youtube.com（內容指令碼）：在影片頁插入學習面板、取得使用者所選學習語言的字幕軌、控制影片的暫停與單句重播。比對範圍涵蓋整個網域而非只有 /watch，是因為 YouTube 是單頁應用程式：使用者從首頁點進影片時不會重新載入頁面，若只在 /watch 注入，指令碼不會被載入。擴充只在 /watch 頁面實際運作，其餘頁面不做任何事；且預設不自動啟動，必須由使用者在該影片上按下「開始學習這部影片」才會開始。

api.anthropic.com 與 generativelanguage.googleapis.com：把該段字幕文字送去分析，產生單字、片語、翻譯與文法說明。使用的是使用者自己在設定頁填入的 API key，兩者擇一，不會同時呼叫。內容指令碼受 CORS 限制無法直接呼叫這兩個端點，因此請求由 service worker 發出。

除上述三者外不存取任何其他網站，不蒐集瀏覽紀錄，也沒有任何屬於開發者的伺服器。
```

**遠端程式碼**：否。所有程式碼都包含在套件內，沒有 `eval`、沒有動態載入的指令碼。

**資料用途申報**（Data usage）

勾選蒐集的類型：

- ☑ **網站內容（Website content）** — 使用者啟動的那支 YouTube 影片的字幕文字、標題與網址，
  傳送給使用者自行選擇並付費的 AI 供應商以產生學習筆記。
- ☑ **驗證資訊（Authentication information）** — 使用者自己的 API key。只存在本機，
  僅作為請求標頭送往該供應商，不會傳送給開發者。
- ☐ 其他所有類型都不勾（個人身分資訊、健康、財務、個人通訊、位置、瀏覽紀錄、使用者活動）

三個必填的聲明全部勾選：

- ☑ 不販售或移轉使用者資料給第三方（上述 AI 供應商為使用者自行選擇的服務，非移轉）
- ☑ 不將使用者資料用於與單一用途無關的目的
- ☑ 不將使用者資料用於判定信用狀況或放貸

## 3. 圖片素材

| 用途 | 尺寸 | 必要性 | 檔案 |
|---|---|---|---|
| 商店圖示 | 128×128 | 必要 | `icons/icon128.png` ✅ |
| 截圖 | 1280×800 | 至少 1 張，最多 5 張 | `store/screenshots/` ✅ 三張 |
| 小宣傳圖 | 440×280 | 必要 | `store/promo-440x280.png` ✅ |
| 跑馬燈宣傳圖 | 1400×560 | 選填 | `store/promo-1400x560.png` ✅ |

兩張宣傳圖都是 `store/make-promo.py` 排出來的，不是生圖模型畫的——生成的圖
會在畫面裡寫出不存在的單字（試過一次，字幕那行變成
`I active subtitles n active suitoos.`）。

跑馬燈那張商店規定 **JPEG 或 24 位元 PNG、不能有 alpha 透明層**。腳本的底圖
用 RGB 模式建（不是 RGBA），河童貼上去時拿它自己的 alpha 當遮罩，貼完就沒有
透明層了，最後再 assert 一次確認。

排版遵守官方素材指引的兩條建議：**避免文字**（只有名稱和一行說明，沒有功能列表）
和**縮到一半還要看得懂**（字級是演算法套出來的，不是寫死的，所以改字不會爆版）。

圖裡不放 Chrome、YouTube、Anki 的標誌，也不放假的「Add to Chrome」按鈕——
別人的商標用了要有授權，而那顆假按鈕使用者會想點但點不動。

圖示四個尺寸已經做好（河童讀書，四角已去背）。原圖是 `icon-source-2000.png`，
要換圖就覆蓋它再跑 `python3 store/make-icons.py`。商店圖示直接上傳 `icons/icon128.png`。

**截圖已經做好五張**（商店上限），在 `store/screenshots/`，按檔名順序上傳：

| 檔名 | 展示什麼 |
|---|---|
| `01-單字與片語整理.png` | 法文。逐句翻譯＋下方的單字卡（含詞性與用法說明）。資訊量最大，放第一張 |
| `02-框選解說.png` | 日文。框選「レジで会話を撮影しました」之後逐詞拆解。一張圖同時做兩件事：證明不是只支援歐洲語言，並展示別的擴充沒有的功能 |
| `03-日文也可以.png` | 日文的逐句對照與單字 |
| `04-逐句複習與翻譯.png` | 整段的逐句對照，其中一句被選取、顯示 `▶` 與 `0.75×` |
| `05-自動暫停的時刻.png` | 影片停在段落結尾、面板已經備好筆記的那一刻 |

排第二的是解說而不是單純的日文畫面，因為「翻譯字幕」的擴充滿街都是，
「框一段問它為什麼這樣說」才是會讓人裝下去的理由。

原圖在 `store/screenshots/raw/`，`store/make-screenshots.py` 把它們裁成 1280×800
並把兩個帳號頭像模糊掉。要加截圖的話，丟一張進 `raw/`、檔名開頭編號排好順序，
重跑腳本就好。

原圖之所以也進版控：處理過程會不可逆地裁切和縮放，沒有原圖的話，哪天商店改規格
或想重新裁一次，就只能重拍。

五張已經滿了。之後想換掉其中一張的話，最值得補的是「匯出的 Anki 檔在 Anki
裡的樣子」——「能匯進 Anki」是會讓人決定安裝的功能，但光看文字沒有說服力。
要換的話建議換掉 `05`，自動暫停那張是五張裡資訊量最低的。

**設定頁那張不要拍**，或拍之前先把 API key 清空——那是唯一會洩漏東西的畫面。
