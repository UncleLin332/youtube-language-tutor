第一次用？Anthropic（Claude）API Key 圖文申請教學
步驟 1 / 4
  1. 先儲值：登入 console.anthropic.com（與 Claude Pro 月費分開計費），點左側 Billing → Buy credits 購買額度（無免費額度，未儲值會回 credit balance is too low）。
  2. 建立金鑰：切到左側 API keys → Create Key，隨意取個名稱（例如 youtube-tutor）。
  3. 立刻複製：sk-ant- 開頭的金鑰僅顯示這一次，請當場按 Copy Key（關閉後無法再看）。
  4. 貼回測試：貼到上方欄位後按「儲存設定」→「測試 API key」。建議在 Billing 設定每月用量上限。
第一次用？Gemini（Google）API Key 圖文申請教學
步驟 1 / 4
  1. 開啟 AI Studio：使用 Google 帳號登入 aistudio.google.com/apikey，點擊右上角 Create API key。
  2. 建立新專案：選擇 Create API key in new project，免手動設定 Google Cloud。
  3. 複製金鑰：複製 AIza 開頭的金鑰（免綁信用卡即可使用免費額度；遇 429 稍候再試即可）。
  4. 貼回測試：貼到上方欄位後按「儲存設定」→「測試 API key」。若在意免費版內容可能用於改善產品，可於專案啟用付費（詳見 Gemini API 條款）。
